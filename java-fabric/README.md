"# Arcane Arsenal — Fabric Edition\n\nFabric mod target: Minecraft Java 26.3, Fabric Loader 0.20.1, Fabric API 0.166.2+26.3, Java 25.\n\n## Included in this initial port\n- Five usable arcane weapons with their abilities: Flame Nova, Thunder Call, Void Veil, Gravity Slam and Lifebloom.\n- Mana costs, passive mana regeneration, cooldowns, level/XP progression (progression state is currently session-only).\n- Arcane Essence, Mana Crystal, Arcane Crystal Ore and Rune Stone.\n- Shaped crafting recipes and block loot tables.\n\nBuild with `gradle build` from this directory. The GitHub Actions workflow builds and uploads the remapped mod JAR. This is an initial Fabric port; it does not yet include parity for Bedrock's custom Riftling mob or world-generation features, and it needs an in-game runtime test."
